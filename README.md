# 🍺 SGIPC — Sistema de Gestión Integral de Producción Cervecera

Sistema web full-stack para la gestión y digitalización de procesos productivos en una cervecería artesanal. Desarrollado como trabajo de grado en Ingeniería de Sistemas (UNAD) y desplegado en producción activa en **Bebidas Coral S.A.S.**

## 📌 Descripción

SGIPC digitaliza la operación completa de una planta de producción cervecera: desde el control de materias primas hasta el inventario de producto terminado, pasando por fermentación y empaque. A diferencia de un proyecto académico convencional, este sistema **opera en un entorno de producción real**, siendo utilizado diariamente por el personal de planta.

El sistema fue diseñado bajo el estándar **IEEE 29148-2018** para ingeniería de requisitos, documentando 29 requisitos funcionales, 31 requisitos no funcionales y 18 reglas de negocio.

## ✨ Funcionalidades principales

- Control y trazabilidad de materias primas
- Gestión del proceso de fermentación
- Registro y control de empaque
- Gestión de inventario de producto terminado
- Módulo de reportes de producción
